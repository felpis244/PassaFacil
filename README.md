## Sobre o projeto

O PassaFácil é uma plataforma web gratuita que ajuda estudantes a praticar conteúdos e se preparar para provas, vestibulares e o ENEM por meio da resolução de exercícios.

As questões são organizadas por matéria, conteúdo e nível de dificuldade, com correção automática e explicação de cada resposta. O aluno acompanha seu desempenho em um painel com estatísticas e um relatório ao fim de cada lição.

Para manter a motivação, a plataforma usa gamificação inspirada no Duolingo: pontos de experiência (XP), sistema de vidas, sequência de dias estudados e ranking entre os alunos. Há ainda um chatbot para tirar dúvidas de português e um painel de administração para gerenciar alunos e questões.

### Tecnologias

HTML5, CSS3 e JavaScript (ES6+) no front-end, Supabase (PostgreSQL e autenticação) como back-end, e Cypress para testes automatizados ponta a ponta.

---

## Como executar e utilizar

Não é necessário instalar nada. Basta abrir o link abaixo no navegador:

**https://passa-facil-alpha.vercel.app/**

Em seguida, crie uma conta na tela de cadastro (ou faça login, se já tiver uma) e escolha uma matéria para começar a resolver questões.
